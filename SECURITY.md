# Security Policy 🔒

## Supported Versions

We provide security updates for the latest major release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability in the Repository Intelligence Platform, please report it via email to security@yourdomain.com. Please include:

- Description of the vulnerability and potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested remediations.

We will acknowledge receipt of your vulnerability report within 48 hours and provide regular progress updates until resolved.
